# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities through GitHub's private vulnerability reporting for this repository. Open the repository's **Security and quality → Advisories** page and select **Report a vulnerability**.

Please do not report security issues in public GitHub issues, discussions, or pull requests. Include the affected revision, a description of the issue, its potential impact, and steps to reproduce it where practical. Avoid including real credentials or personal data in a report.

Reports are private to the maintainers while they are reviewed. No response-time or remediation guarantee is made.
